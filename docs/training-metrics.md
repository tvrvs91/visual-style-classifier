# Метрики обучения моделей

Сырые данные **четырёх итераций** fine-tuning'а на собственном датасете
визуальных стилей. Из этих таблиц в любой момент можно восстановить
графики (loss/accuracy кривые) для дипломной работы.

## Сводная эволюция

| Итерация | Классов | Best val acc | max/min imbalance | Bias-эффект | Воспроизводимость |
|---|:---:|---:|---:|---|---|
| v1 (наивный fine-tune) | 8 (с moody+street) | **0.678** | 5.0× | сильный на minimalist | нет |
| v2 (балансировка) | 7 (street удалён) | **0.724** | 1.92× | заметный на moody | нет |
| v3 (новая таксономия) | 8 (без moody, +monochrome +neon) | **0.726** | 1.22× | устранён | split в эфемерной FS, потерян |
| **v3.1 (воспроизводимая)** | **8 (та же таксономия)** | **0.694** | **1.22×** | **устранён** | **полностью** |

**Почему v3.1 чуть ниже v3 (0.694 vs 0.726).** При переобучении на честном
split'е (тот же `seed=42`, те же шаги предобработки в детерминированном
порядке — см. M19 в `work-log.md`) accuracy снизилась на 3 пп. Это
**нормальная статистическая дисперсия** для val_set из 893 фотографий
и стохастичных факторов обучения (RandomResizedCrop, перетасовка пар
в WeightedRandomSampler, инициализация головы). Главное — **per-class
картина и качественные выводы сохранились полностью** (см. §v3.1 ниже).

**Главный сдвиг качества от v1 к v3** — не в абсолютной accuracy
(67.8% → 72.6%, +4.8 пп), а в **исчезновении bias-эффекта**: в v1 модель
сваливалась в minimalist на 50%+ кадрах, в v3 распределение
предсказаний по классам в коридоре 0.87–1.08 от истинного — модель
делает осмысленный выбор, а не «безопасное предположение».

## Анализ

### EfficientNet-B0
- **Плато с эпохи 5.** Train loss продолжает падать (0.97 → 0.86), val loss/acc стоят. Лёгкое переобучение, но не катастрофическое.
- **Финальный gap train↔val:** train ≈ 0.86, val ≈ 0.95 → разница ~0.09. Терпимо.
- **Аргумент в пользу:** в 5–6 раз меньше и быстрее. Хорош для production / mobile.

### ResNet-50
- **Кривая ещё не вышла на плато к 10 эпохе** — train и val loss продолжают снижаться. Можно было бы выжать ещё 1–3 пп точности продолжив обучение.
- **Лучше генерализуется**: val loss 0.78 против 0.95 — модель более уверена в правильных предсказаниях, не только в топ-1.
- **Аргумент против:** в 6 раз тяжелее по диску, ×3 по времени инференса.

### Вывод для диплома
Обе модели — рабочий результат для 8-классовой задачи на ограниченном датасете
(67–73% top-1 — стандартный диапазон для такого размера и сложности). ResNet-50
объективно точнее на ~5 процентных пунктов, но EfficientNet-B0 даёт лучший
баланс точность/инфраструктура — оправданный выбор для production-сервиса
с CPU-инференсом.

В отчёте можно представить **обе модели как сравнительный эксперимент**,
показывающий обоснование выбора EfficientNet-B0 для финального деплоя.

### Анализ monochrome (F1=0.52, ниже ожидаемого)

`monochrome` определяется только нулевой насыщенностью — параметр,
который **орто-пересекается** с композиционными и тональными признаками
других классов. Топ-путаницы из confusion matrix:

```
monochrome → minimalist (13)   B&W минималистичные кадры
monochrome → vintage    (12)   B&W плёночные фото
monochrome → dramatic   (10)   B&W высококонтрастные
```

Это **методологическое ограничение single-label классификации**:
один кадр может одновременно быть `monochrome` (по цвету) и
`minimalist` (по композиции) или `vintage` (по обработке). Решение
— переход на multi-label (sigmoid + BCE), что обсуждается в разделе
«Направления развития».

## Что бы я улучшил для следующей итерации

1. **Дольше обучать ResNet-50** — кривая не насыщена, ещё 5–10 эпох вероятно дадут 73–75% val acc.
2. **Test-time augmentation** — усреднение по 5 аугментациям одного кадра — стабильно даёт +1–2 пп.
3. **k-fold cross-validation** — снизит чувствительность метрик к
   составу val (особенно для `dark`, `minimalist` где −8 пп между v3 и v3.1).
4. **Сохранять split на Drive** рядом с весами (`split_manifest.json`)
   — устранит проблему data leakage при переобучении.

## Готовность к графикам диплома

Для построения двух кривых (по эксперименту):

```
X: epoch
Y1: train_loss (синий)
Y1: val_loss (оранжевый)
Y2 (правая ось): val_accuracy (зелёный)
```

Данные выше уже структурированы — копировать в pandas / Excel / matplotlib
напрямую без переразметки.
