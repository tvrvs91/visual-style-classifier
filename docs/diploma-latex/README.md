# LaTeX-шаблон диплома ЯрГУ (UTF-8)

Перекодированная UTF-8 версия [dchaly/diploma](https://github.com/dchaly/diploma) — официального LaTeX-шаблона дипломной работы факультета ИВТ ЯрГУ им. П. Г. Демидова.

## Что изменено относительно оригинала

Оригинал использует устаревшую кодировку **Windows-1251**, что вызывает
проблемы при компиляции в современных онлайн-сервисах (Overleaf, ShareLaTeX и др.):
русский текст рендерится как мусор.

В этой папке:
- Все `.tex` и `.cls` файлы перекодированы в **UTF-8**.
- Объявления кодировки заменены:
  - `% !TeX encoding = windows-1251` → `% !TeX encoding = UTF-8`
  - `\inputencoding{cp1251}` → `\inputencoding{utf8}`
  - `\RequirePackage[cp1251]{inputenc}` → `\RequirePackage[utf8]{inputenc}`
- Логика шаблона, классы, оформление — **не тронуты**, всё работает идентично оригиналу.

## Использование в Overleaf

1. Скачай папку `docs/diploma-latex/` целиком как zip из GitHub:
   ```
   https://github.com/tvrvs91/visual-style-classifier/tree/ml-deep-dive/docs/diploma-latex
   ```
   Удобный способ: открой [downgit](https://download-directory.github.io/), вставь
   URL папки выше — получишь zip только этой подпапки.

2. На [overleaf.com](https://overleaf.com) → **New Project** → **Upload Project** → загрузи zip.

3. В настройках проекта (Menu → Settings) убедись:
   - **Main document:** `diplExample.tex`
   - **Compiler:** `pdfLaTeX`
   - **TeX Live version:** 2023 или новее

4. Нажми **Recompile** — должен собраться PDF с правильной русской типографикой.
